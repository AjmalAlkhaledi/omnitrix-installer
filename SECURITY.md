# Security Policy

## Supported versions

Security fixes are released for the latest minor version.

## Reporting a vulnerability

Please do not open public issues for security problems. Report them privately by email to
Ajmal Alkhaledi <ajmalalkhaledi@gmail.com> with a description, affected versions and, if
possible, a minimal reproduction. You will receive an acknowledgement within a few days, and
a fix and advisory will be coordinated with you before public disclosure.
